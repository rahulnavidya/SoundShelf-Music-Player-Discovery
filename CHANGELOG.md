# Changelog

## [1.0.0] - 2026-11-22
### Added
- Complete native Jetpack Compose & Media3 (`ExoPlayer` + `MediaSessionService`) music player.
- Incremental `MediaStore` local music scanner, Storage Access Framework audio import, folder exclusions, and duplicate detection.
- `AudioInspector` displaying genuine file codec, bitrate, sample rate, bit depth, and channels.
- `LocalMetadataEditor` with Photo Picker cover replacement and reversible undo snapshots.
- Static playlists, multi-rule Smart Playlists, automatic local mixes, and M3U/M3U8 import/export.
- Modular online providers: Audius, Jamendo CC, isolated YouTube Music Experimental handoff, and Spotify external handoff.
- Lyrics Studio with `.lrc` parser/serializer, timing offset, and inline timestamp editor.
- Download Finder with legitimate source discovery, SHA-256 verification, and Find a Better Version safe library upgrade.
- 15 complete curated themes, Custom Theme Editor, and 5 Now Playing visual layouts.
- Local-Only Offline Mode privacy toggle and GitHub Actions APK build workflow.
